# Origin

A gamified learning and productivity web app.
Your progress changes more than just you.

> The village grows as you grow.

## Status

Phase 1 — foundation: project setup, React frontend, Django API,
authentication, protected dashboard.

## Tech stack

- Frontend: React + Vite (JavaScript)
- Backend: Django + Django REST Framework
- Database: SQLite (development) → PostgreSQL (production)

## Architecture

React → HTTP/JSON API → Django → ORM → Database
